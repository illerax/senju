# Senju — требования

Senju (千手, «тысяча рук») — кроссплатформенный терминал для работы с несколькими проектами и AI-агентами. Идея взята у [cmux](https://github.com/manaflow-ai/cmux), но нужен только самый необходимый минимум, и всё должно работать на Linux.

## Платформы

- Linux (X11 и Wayland) — основная платформа.
- macOS и Windows — должны работать, но вторичны.

## Структура рабочего пространства

- **Проекты.** Список проектов в боковой панели. Проект можно создать, переименовать, удалить, поменять порядок.
- **Окна.** Внутри проекта несколько окон (вкладок). Окно можно создать, переименовать, закрыть, поменять порядок.
- **Панели.** Окно делится на панели по горизонтали и по вертикали, с любой вложенностью.
  - Размер панелей меняется перетаскиванием разделителя.
  - Фокус переключается мышью и клавишами (стрелки).
  - Закрытая панель освобождает место, соседние панели его занимают.
- Каждая панель — полноценный терминал со своим shell.

## Сохранение и восстановление

После закрытия терминала или перезагрузки компьютера всё должно вернуться.

### Всегда восстанавливается

- Проекты, окна, их имена и порядок.
- Раскладка панелей и их пропорции.
- Активный проект, активное окно, панель в фокусе.
- Рабочая папка каждой панели.
- Содержимое прокрутки каждой панели.

### Запущенные программы

Восстановление идёт по трём уровням, для каждой панели выбирается лучший доступный:

1. **Процесс продолжает жить.** При закрытии окна, падении или обновлении интерфейса процессы не останавливаются, и после повторного открытия всё продолжается с того же места. Перезагрузку ОС этот уровень не переживает.
2. **Возобновление сессии агента.** После перезагрузки AI-агенты продолжают тот же диалог.
   - Обязательно: Claude Code (`claude --resume <id>`), с учётом `CLAUDE_CONFIG_DIR`.
   - Желательно: Codex CLI, Gemini CLI, OpenCode, Aider, nvim с сессиями.
   - Поддержка агента описывается рецептом: как узнать id сессии и какой командой её открыть. Новые агенты добавляются рецептом, без изменения кода.
   - Если в одной папке открыто несколько панелей с агентами, каждая возвращается к своей сессии.
   - Если пользователь сам закрыл агента, после перезагрузки он не запускается.
3. **Перезапуск команды.** Остальные программы запускаются заново той же командой, в той же папке, с тем же окружением.
   - Долгоживущие команды из списка (dev-серверы, логи, мониторы) перезапускаются автоматически.
   - Остальные не перезапускаются сами: в панели появляется кнопка «Запустить снова».
   - Список автоперезапуска настраивается.

### Надёжность

- Состояние сохраняется сразу после каждого изменения, а не только при выходе.
- Падение или отключение питания не портит сохранённое состояние.

## Управление

- Горячие клавиши для всех основных действий: новый проект или окно, деление панели, закрытие, переключение фокуса и окон.
- Горячие клавиши не перехватывают сочетания, нужные программам внутри терминала (vim, Claude Code, tmux).
- Копирование и вставка, выделение мышью.

## Не входит в объём

- Встроенный браузер, уведомления, интеграции с внешними сервисами.
- Работа с удалёнными машинами, кроме обычного ssh внутри панели.
- Синхронизация между компьютерами.
- Темы и плагины сверх минимальных настроек шрифта и цветов.

## Принятые решения

- Стек: Electron + TypeScript + xterm.js + node-pty.
- Процессы панелей живут в отдельном фоновом процессе (демоне), интерфейс к нему подключается.
- Всё состояние хранится в одном JSON-файле.
- Подробная оценка и архитектура: https://claude.ai/artifact/Ro8GQqc6ifZM4xNyBeE9HZ
